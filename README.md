# sventmueller/tap

Homebrew casks for [Splat](https://github.com/sventmueller/splat), the Markdown editor for macOS with a live, editable
preview.

```sh
brew install --cask sventmueller/tap/splat
```

Splat needs macOS 14 or later on Apple Silicon. `brew upgrade --cask splat` installs new versions;
`brew uninstall --zap --cask splat` also removes its settings and caches.
